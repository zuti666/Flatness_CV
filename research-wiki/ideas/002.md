# Core Idea

**Observation gap**: AS^(1) (first-order adapter-subspace flatness) improves current-task generalization and reduces sharpness, but does NOT explicitly encode which update directions are harmful to previous tasks. A flat minimum is not necessarily a "safe" minimum for old tasks.

**Proposed method**: Flat-and-Stable SeqLoRA — a joint objective combining:
1. **AS^(1) current-task flatness**: first-order sharpness minimization within W_{Δ,t} (adapter admissible subspace) controls local curvature and improves plasticity.
2. **Past-task Fisher penalty**: past-task Fisher-weighted regularization biases the LoRA update away from old-task sensitive directions, controlling forgetting.

**One-line**: AS^(1) shapes the geometry of the current update; the past Fisher penalty shapes the direction of that update.

## Full Objective (Task t)

```
min_{φ} L̂_t(W_0 + ΔW(φ))
       + λ_flat · S^(1)_{t,Δ}(φ)
       + (λ_ewc/2) · (φ - φ*_{t-1})^T · (F^φ_{1:t-1} + ηI) · (φ - φ*_{t-1})
```

Where:
- φ = {A, B} = shared SeqLoRA parameters (only trainable params)
- W_0 = frozen backbone
- S^(1)_{t,Δ}(φ) = AS^(1) term: max_{|ε|≤ρ, ε∈W_Δ} |∇_φ L̂_t(W_0 + ΔW(φ+ε))| (gradient norm in adapter subspace)
- F^φ_{1:t-1} = accumulated past-task Fisher on φ (estimated from full-dim FIM projected to φ space)
- φ*_{t-1} = optimal LoRA params at end of task t-1
- After task t: F^φ_{1:t} = γ · F^φ_{1:t-1} + F^φ_t (cumulative Fisher with decay)

## Why SeqLoRA Specifically

SeqLoRA uses a SINGLE shared LoRA pair (A,B) across all tasks. Forgetting occurs because φ*_{t-1} → φ*_t — the same parameters drift away from old optima. There are no separate branches to protect; the only anti-forgetting mechanism is regularization on φ. This makes SeqLoRA the natural testbed:
- IncLoRA/OLoRA add new adapter pairs per task → partial isolation by design → Fisher penalty less necessary
- SeqLoRA has NO structural isolation → both flatness AND Fisher are needed simultaneously

## Two Roles Are Orthogonal

| Component | Controls | Mechanism |
|-----------|----------|-----------|
| AS^(1) | Local geometry of current update | Minimizes gradient norm in W_{Δ,t} → flatter basin → better plasticity |
| Past Fisher | Direction of current update | Penalizes movement along old-task sensitive directions → less forgetting → better stability |

These are NOT redundant:
- A flat update can still be in the wrong direction (high Fisher-weighted drift)
- A direction-controlled update (Fisher) can still be in a sharp basin (poor generalization)

## Connection to Prior Theory (idea:001)

The Forgetting-Sharpness theorem (proposed extension of ICML 2026 paper) motivates this method directly:

```
Forget(i→t) ≤ S_i^Δ · Γ(i,t) · η_t
```

AS^(1) minimizes S_i^Δ (sharpness term). The Fisher penalty implicitly reduces Γ(i,t)·η_t by penalizing movement in the directions where task i and task t overlap. The method is thus the natural algorithmic realization of the forgetting bound.

### Metrics Per Condition

- AvgAcc, FinalAcc, Forgetting, BWT
- S^(1)_{t,Δ} (subspace gradient norm sharpness)
- λ_max(H_{Δ,t}), tr(H_{Δ,t}) (Hessian curvature)
- D^Fisher_t = (φ*_t - φ*_{t-1})^T F^φ_{1:t-1} (φ*_t - φ*_{t-1}) (Fisher-weighted drift)
- Normalized drift: D^Fisher / ‖Δφ‖² (to distinguish direction control from magnitude suppression)

### Mechanism Predictions

- AS^(1) only: reduces sharpness metrics, improves plasticity (A_{t,t}), not necessarily stability
- Fisher only: reduces D^Fisher, improves stability (BWT), not necessarily plasticity
- Full: both reduced; best AvgAcc and BWT

## Failure Modes to Watch

- If AS^(1) and Fisher point to conflicting gradient directions → training instability (need λ-tuning)
- If Fisher-weighted drift ≈ plain ‖Δφ‖² → Fisher is just a magnitude penalty, not directional → need normalized drift metric
- If SeqLoRA already forgets too catastrophically at baseline → Fisher alone might dominate (no flatness gap visible)

### Interpretation: Near-Orthogonal Division of Labor

The original "synergy" hypothesis (cos_flat_fisher > 0) does NOT hold.
The actual finding is stronger: **cos_flat_fisher ≈ −0.02 to −0.04 across all tasks**, i.e., near-orthogonal.

**Revised mechanism claim**:

| Component | Gradient norm (vs. clean) | Direction (vs. flat component) |
|-----------|:------------------------:|:------------------------------:|
| AS^(1) flatness | **3.4–6.7× clean** — dominates training | Defines primary gradient direction |
| Fisher | **0.014–0.286% of clean** — tiny | Near-orthogonal to flatness (cos ≈ −0.02) |

The near-zero cosine means the two components address **nearly orthogonal subspaces** of the gradient space:
- AS^(1) controls current-task loss geometry (dominant, cos_clean_flat ≈ +0.65 = well-aligned with task)
- Fisher applies a micro-correction in directions orthogonal to the flatness gradient → constrains old-task sensitive dimensions that flatness does not affect

**This is a stronger argument than "synergy"**:
- If cos ≈ +1: one component would be redundant
- If cos ≈ −1: components would fight each other
- cos ≈ 0: they solve DIFFERENT problems in orthogonal subspaces — true complementarity

**Implication for EWC-LoRA + C-Flat comparison**:
- EWC-LoRA alone: Fisher gradient in one subspace, no flatness
- C-Flat alone: flatness in another subspace, no Fisher
- Naive EWC-LoRA + C-Flat (plug-and-play): Fisher and flatness gradients may partially overlap (C-Flat perturbs full space, not adapter-subspace)
- **Our method**: AS^(1) in adapter subspace + Fisher in ΔW space → the two are provably nearly orthogonal by the geometric separation of the adapter update directions from old-task Fisher directions
