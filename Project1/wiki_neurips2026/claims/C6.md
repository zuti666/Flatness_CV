title: Raw factor-space sharpness (Sh_AB) is parameterization-dependent; Sh_Delta/W_tangent is invariant
type: empirical
status: pending — rescaling control (Exp G) required
---

The same effective LoRA update ΔW = BA can be reparameterized as (A/c, cB) for any scalar c, leaving ΔW unchanged while changing Sh_AB. If Sh_AB varies with c while model output and Sh_Delta remain stable, this proves raw factor-space sharpness is not the correct theoretical object.

**Required experiment (Exp G)**:
- Checkpoint: task-9 or task-19 from Exp E/F
- Scales: c ∈ {0.25, 0.5, 1, 2, 4}
- Transform: A' = A/c, B' = cB → ΔW = B'A' = BA unchanged
- Metrics: Sh_AB, Sh_Delta/W_tangent, model accuracy (must be unchanged)
- Expected: Sh_AB varies with c; Sh_Delta stable; accuracy unchanged

**Theoretical grounding**: Theorem B.2 (support reduction) proves the bound-relevant quantity is W_{Δ,t}, which is basis-invariant. Sh_AB depends on the LoRA factorization and is therefore NOT the bound-relevant object. Exp G is the empirical validation.
